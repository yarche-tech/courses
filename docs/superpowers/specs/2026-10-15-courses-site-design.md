# Сайт курсов: дизайн

Дата: 2026-10-15
Статус: на ревью

## Цель

Личный учебный сайт по 8 направлениям с удобным интерфейсом, как у Stepik.
Задачи решаются и проверяются локально, без ограничений на окружение.

Критерий успеха: открыл урок → прочитал → ответил на вопросы самопроверки →
решил задачу в своём редакторе → `pytest` показал результат.

## Принятые решения

- **Статический сайт без бэкенда.** Платформа с раннером кода, API и
  Electron-клиентом рассматривалась и отклонена как лишнее усложнение.
- **Один репозиторий, один сайт, 8 разделов.** Общий поиск и общая навигация.
- **MkDocs Material**, деплой на **GitHub Pages** через GitHub Actions на push в `main`.
- **Сайт и репозиторий публичные.**
- **Код пишется и проверяется локально**: `pytest` плюс `docker compose`
  (Postgres, Redis) для задач, которым они нужны.
- **AI-помощник** — Claude Code в чате. В сайт он не встраивается.
- **Прогресс** отмечается чек-листом в `PROGRESS.md`. Трекер в браузере не делаем.

## Не делаем (non-goals)

Выполнение кода в браузере, учётные записи, серверный прогресс, встроенный AI,
десктоп-приложение, интерактивные квизы на JS.

## Структура репозитория

```
mkdocs.yml                     exclude_docs: superpowers/ (спеки и планы не публикуются)
docs/
  superpowers/specs|plans/     проектные документы, не часть сайта
  index.md                     главная: 8 направлений, как учиться
  <slug>/index.md              обзор раздела: цели, порядок тем, ресурсы
  <slug>/NN-<topic>.md         урок
exercises/<slug>/NN-<topic>/
  task.py                      заготовка (функции с NotImplementedError)
  test_task.py                 тесты
  README.md                    условие (дублирует ссылку на урок)
solutions/<slug>/NN-<topic>/task.py   эталонные решения
conftest.py                    подмена task.py на эталон при COURSES_SOLUTIONS=1
docker-compose.yml             Postgres 17 + Redis 7 для задач
pyproject.toml                 зависимости (uv), Python ≥ 3.13
PROGRESS.md                    чек-лист тем
.github/workflows/             сборка сайта + проверка эталонов
```

## Формат урока

Markdown с front matter:

```yaml
---
title: Декораторы
status: draft | reviewed        # reviewed — проверено на точность и полноту
sources:                         # откуда взят материал
  - https://github.com/justxor/python-primery-koda-2026 (MIT)
---
```

Структура тела урока:
1. **Зачем.** Какую проблему решает тема.
2. **Теория** с примерами кода. Для формул, диаграмм и подсветки используются
   `pymdownx.arithmatex`, Mermaid и superfences.
3. **Подводные камни.** Частые ошибки и вопросы с собеседований.
4. **Самопроверка.** 5–10 вопросов, ответ спрятан в сворачиваемый блок
   `??? question "…"`.
5. **Практика.** Ссылки на `exercises/...` и команда запуска.
6. **Дальше.** Первоисточники для углубления.

Объём урока зависит от глубины направления: для «повторение» конспект и
самопроверка, для «глубоко» полный разбор и 3+ задачи.

## Задачи

- `task.py` содержит заготовку, которую решаешь ты; `test_task.py` содержит тесты.
  Запуск: `pytest exercises/python-advanced/01-decorators`.
- Если задаче нужны Postgres или Redis, тесты берут DSN из переменных окружения
  (значения по умолчанию совпадают с `docker-compose.yml`). Если сервис недоступен,
  тесты помечаются как пропущенные с подсказкой `docker compose up -d`.
- Тесты используют только `import task`. `conftest.py` при `COURSES_SOLUTIONS=1`
  подставляет в путь импорта директорию из `solutions/`. Так CI проверяет, что
  тесты проходят на эталоне, а пользователь получает падающие тесты на заготовке.
- **Твои решения не коммитятся в публичный `main`.** Работаешь в локальной ветке
  `work` (или в приватном форке). `main` хранит только заготовки.

## Контент и источники

- Сырьё — репозитории github.com/justxor. Оценка: материал свежий и технически
  аккуратный, но по глубине это шпаргалка, а не курс, и похоже на AI-генерацию.
  Каждый урок проходит путь: импорт → проверка точности → расширение → `status: reviewed`.
- **Лицензии.** `python-primery-koda-2026` и `math-for-ai-2026` распространяются
  под MIT: можно заимствовать с указанием авторства в `sources` и в
  `docs/credits.md`. Остальные репозитории (`pythonroamap2026`,
  `MachineLearningRoadmap`, `Aiagentsfullcourse` и др.) без лицензии: используются
  только как ориентир по темам, текст пишется заново, дословное копирование запрещено.
- Пробелы в источниках (сети, ОС, алгоритмы, глубокий Postgres/Redis, system design,
  LLM с нуля) закрываются по первоисточникам: документация, учебники, курсы из
  обзорной таблицы ресурсов.

## Сборка и проверка (CI)

- Job `site`: `mkdocs build --strict` (битые ссылки ломают сборку), затем деплой на Pages.
- Job `solutions`: `COURSES_SOLUTIONS=1 pytest`, с сервисами Postgres и Redis в GitHub Actions.
- Локальный просмотр сайта: `mkdocs serve`.

## Первый этап (MVP)

1. Каркас: `mkdocs.yml` (тема, русский поиск, вкладки разделов), главная, 8 обзорных
   страниц разделов, `PROGRESS.md`, `pyproject.toml`, `conftest.py`,
   `docker-compose.yml`, CI, `docs/credits.md`.
2. Первая тема полностью: Python Advanced → «Декораторы». Урок, самопроверка,
   3 задачи с тестами и эталонами.
3. Сайт опубликован на GitHub Pages, ссылка работает.

Дальше — тема за темой, по одной теме за итерацию. Порядок: два трека, инженерный
(1→2→3→4) и AI (5+6 → 7 → 8).
